# Video Streaming Platform for IM900

**Software Version**

Efinix version 2026.1  
Ubuntu 22.04.5 LTS


**Project Description**

This project implements video streaming from a MIPI camera input connected to the SMT135-C carrier board.  The project is configures for the SONY IMX900 camera sensor.  The design creates video packets over the SFP+ connector which can be viewed using a 10G NIC running on a local PC.  A python program is included in the source file to display the image.
